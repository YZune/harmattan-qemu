## 实验性兼容范围

研究基线为 `621c7f7`（2026-09-05）。以下是该工作区的记录结果，不是对其他客体镜像或宿主工具链的保证。

| 范围 | 记录结果 | 边界 |
| --- | --- | --- |
| ARM64 宿主 / ARM32 客体 | 原生 QEMU、内核直启、存储及 framebuffer | 实验性 N00 板型，未完整模拟 OMAP3/N9 |
| 原版 Home | 桌面窗口、原资源与触摸滚动 | 最小救援启动，不是完整产品启动和服务图 |
| Calculator | 启动、`2+3=5`、边缘返回及同实例恢复 | 不代表任意应用兼容 |
| Notes 与 Maliit | 输入、退格、符号布局、客体内保存及键盘重开 | 原英国英语布局；快照运行之间不保留内容 |
| 合成器 | 排序/pixmap 修复、动画中间帧及显示交接 | 采样零黑帧不是 FPS 或普遍无闪烁保证 |
| 状态栏 | 原版服务、本地时间与分钟更新 | 不提供真实蜂窝、电池或设备遥测 |
| Cocoa 生命周期 | 取消/确认关闭窗口、Quit 菜单及工作线程退出 | 原 UI 审计未直接验证 Dock 菜单 |
| 输入活动 | 输入申请、8 秒空闲释放、重获及退出清理 | 不承诺固定性能倍数 |

研究基线记录了 220 项主机测试通过。原始复现日志包含本源码发布以外的路径和运行材料；本次提供测试/诊断代码与整理后的范围说明，不携带全部历史日志。

## 公开源码导出验证

2026-09-05，导出树的 224 项主机测试（220 项基线测试及 4 项导入保护测试）在 Apple Silicon macOS 上通过，包括使用合成图像的原生几何测试。主机测试通过与客体启动、原素材验收是不同层面的结论。由于开发沙箱限制本地 socket，相关测试在沙箱外执行。

额外的发布构建及运行检查见 [release-validation.json](release-validation.json)。请按各项范围解读，未测试字段不表示通过。GitHub Actions 另外在 macOS 与 Linux 上执行源码检查和主机测试。

macOS 预编译预览版另有[验证记录](release-preview-validation.json)，覆盖搬移、私有输入导入和联合客体回归。

从两份固定 SDK/固件原始输入完整重建的结果见[客体准备验证记录](guest-preparation-validation.json)：原始文件摘要保持不变，只读文件系统检查通过，246 项宿主测试及已发布应用的 Home、Notes、键盘、计算器和切换动画联合无窗口回归通过。支持的准备路径见[资源获取与准备指南](guest-inputs.zh-CN.md)。

源码现已支持以[原版开机画面](boot-animation.zh-CN.md)覆盖原有启动检查。[验证记录](boot-animation-validation.json)覆盖干净原生构建、257 项宿主测试及可见 Cocoa 启动、输入和退出。已经下载的预览应用需要重新构建才能包含此改动。

## 尚未完成

- Linux/Windows 运行时移植、另一台 Mac 独立验证，以及 Developer ID 签名和公证。打包运行时及仍需提供的客体输入见[预编译预览版](releases.zh-CN.md)。
- 新增原始材料准备流程的独立复现、更多介质版本的支持，以及可再分发的客体基线。
- 完整 EGL/GLES、SGX 仿真及任意 ARMEL 包兼容。
- 完整 Upstart/Aegis/设备服务、蜂窝、相机、音频、网络和准确物理传感器。
- 通用保存/恢复、机器复位、挂起与唤醒兼容性。
- 全部应用、键盘语言、旋转方向、无障碍及长时间会话。
- splash 与所有交接模式的组合；正常路径仍关闭 splash。

原始记录中，关闭动画和活动的旧 GPU 诊断曾出现 Calculator 身份检查失败及非法调用；之后正常联合 usability 配置通过。不要把旧模式失败记为通过，也不要认为各模式等价。
