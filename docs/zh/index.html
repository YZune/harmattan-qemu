使用之前

现在能做到什么？

这是完整的 Nokia N9 模拟器吗？

这是实验性的 N00/QEMU 移植，组合 PR1.0 时期的模拟器内核与适配层、PR1.3 量产用户态。当前可体验部分原版界面与应用；完整 N9 硬件、GPU 和所有应用兼容性尚未实现。

支持哪些电脑？

当前预编译预览版要求 Apple Silicon、macOS 26 或更高版本及 APFS。Linux 与 Windows 的完整运行时尚未支持。应用采用 ad-hoc 签名，尚未使用 Developer ID 签名或公证。

下载后可以直接启动吗？

还需要按指南准备指定的 PR1.3 磁盘及匹配的模拟器内核。仓库与预览包不附带固件、客体内核、字体或第三方机身素材。

没有系统镜像也能参与吗？

可以。阅读补丁、改进文档和运行无需固件的宿主测试即可开始。仓库提供中英文贡献指南与 AGENTS.md，方便使用 coding agent 协作。
